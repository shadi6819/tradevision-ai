Build a full-stack AI-powered web application named "TradeVision AI" that is optimized for deployment on Vercel.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- TailwindCSS
- shadcn/ui
- Framer Motion
- Vercel AI SDK
- OpenAI API support (API key via environment variable)
- Fully responsive
- Dark modern trading dashboard UI
- No database required initially
- Ready for one-click Vercel deployment

==================================
IMPORTANT AI INSTRUCTIONS
==================================

The AI should never randomly guess.

If the uploaded chart is blurry, cropped, too zoomed, lacks timeframe visibility, or lacks sufficient information, it must clearly respond:

NO TRADE

and explain why.

The AI must always explain its reasoning.

Never only say UP or DOWN.

Always explain the logic.
